# Алмазный меридиан: полезные ископаемые Якутии — версия 3

Интерактивная карта для конкурсной номинации №3, 9 класс.

## Что изменено
- Республика Саха (Якутия) выделена отдельным контуром и лёгкой заливкой.
- Начальный вид карты настроен именно на территорию Якутии.
- Вместо обычных точек используются тематические SVG-иконки: алмаз, золотой слиток, нефтяная капля, уголь, олово, редкоземельные металлы, железная руда.
- Каждая иконка кликабельна.
- В карточке объекта: название, вид сырья, район, год открытия, этап освоения, краткая история, координаты и ссылка на источник.
- Добавлены поиск, 7 тематических слоёв, кнопки «Показать всё» и «Показать Якутию», масштаб, навигация и мини-исследование.
- Используется OpenFreeMap + MapLibre, а не tile.openstreetmap.org.
- Добавлена явная оговорка, что карта учебная и не является полным государственным кадастром.

## Запуск
Откройте `index.html` в браузере при подключённом интернете.

## Публикация
Для конкурсной «активной ссылки» удобно загрузить папку в GitHub Pages, Netlify или другой статический хостинг. Регистрация пользователя на самой карте не требуется.

## Источники
Подробные ссылки находятся внутри `index.html` и в файле `sources.txt`.
